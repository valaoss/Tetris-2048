# 🧩 MergeTris — Tetris × 2048

A Tetris and 2048 hybrid: falling tetrominoes carry numbered tiles, and equal tiles merge when they touch. Includes tetromino rotation, scoring, best-score saving, music and a side panel with the next piece.

> 🇹🇷 Tetris ile 2048'i birleştiren bir oyun: düşen parçalardaki sayılı karolar aynı değerdekilerle birleşir. Döndürme, puanlama, en yüksek skor kaydı ve müzik içerir.

## Tech
Python · pygame · tkinter · stddraw

## Run
```bash
pip install pygame
python Tetris_2048.py
```

## Controls
| Key | Action |
|---|---|
| ← → | Move |
| ↑ | Rotate |
| ↓ | Soft drop |
